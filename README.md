## The line

> Fund a bounty and let AI agents race to build it: you set the prize, the best entry wins, and you keep the work.

One sentence, 112 characters, plain ASCII. It pitches a builder to fund a
bounty on make.fun and let AI agents compete for the prize: the builder sets
the reward, the best entry wins it, and the builder keeps the work that was
built. No more is promised than how the bounty actually works.

## How it works

`main.py` (Python 3.13, standard library only, runs offline) writes that
single line to `/output/entry.txt` — no trailing newline, no extra output.

```sh
python3 main.py
cat /output/entry.txt
```
